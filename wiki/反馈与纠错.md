# 反馈与纠错

[免登录匿名反馈表单](https://tcnrkcsneh6s.feishu.cn/share/base/form/shrcn1OtilSVxBkMSeYIFA7fcNg) · [GitHub公开问题区（可选，需账号）](https://github.com/hint-lab/shu-baoxiao-skill-and-wiki/issues)

首选飞书匿名表单，不需要飞书或GitHub账号。内容由项目维护者在专用反馈收件箱查看，填写者不能浏览其他人的反馈。可反馈实际报销与知识库不一致、清单漏项、政策更新、识别错误或Skill使用故障。这里是知识库纠错入口，学校报销仍按学校流程办理。

## 填写什么

只需说明事项/物品和实际问题，其余按已知情况补充：学院、经费类型、业务年月、原判断、使用版本、办理状态和公开依据。不知道就留空；区分未申报、待审核、退回、审核通过未付款和已付款。只有口头告知或实际经历时直接说明来源，不补造书面依据。

仅提交脱敏文字。不要填写姓名、学工号、手机号、账户、发票号码、签名、密钥、私有链接或完整聊天记录，不上传原件和附件。可先使用[脱敏模板](../skills/shu-baoxiao/assets/反馈模板.txt)。

## 让AI代填

对AI说：**“请把这条差异脱敏后提交给知识库维护者。”** 这就是提交该条反馈的授权，内容足够时不重复询问。

宿主按[结构化示例](../skills/shu-baoxiao/assets/反馈提交示例.json)整理到授权本地或临时目录。完成隐私检查后设置`privacy_checked=true`，再运行：

```bash
python3 "<技能目录>/scripts/submit_feedback.py" --payload "<本地脱敏反馈.json>"
```

脚本只在本地校验并返回`form_fields`和表单链接。有浏览器工具的宿主按题目填写、提交，看到“提交成功”后才能报告已提交；没有浏览器工具则提供草稿和免登录链接。目前脚本没有可用POST接口；默认加`--submit`只会返回`browser_required`和未提交状态，不会偷偷换成GitHub发布。

宿主应核对网页确实保留了输入内容、题目与字段对应，不能只依赖填写动作的返回值。记录本地提交结果以免重复提交；超时或结果不明时说明未确认，不盲目重试。表单尚无公开的单条查询或自动回复接口，不生成虚构的反馈链接、编号或处理进度。

## 当前收集方式与验收

2026-10-29已用未登录窗口完成匿名提交，并在维护端核对到相同测试标记；没有公开底表读取权限。公开配置见`references/knowledge/feedback-config.json`，仅含收集入口和能力状态，不包含管理链接或凭据。

维护者于2026-10-29选择先启用飞书匿名表单，现阶段API暂不部署。使用者直接填写表单，或让有浏览器能力的AI代填即可，无需配置服务器、升级套餐或提供API密钥。表单URL不是POST接口。今后如果另行接入API，应将写表凭据留在服务端，并实际核对记录入表；HTTP成功响应不能单独证明已存储。

## 可选的GitHub公开反馈

使用者明确选择公开渠道后，可使用GitHub表单或宿主已有的GitHub工具。本机已有`gh`授权时可运行：

```bash
python3 "<技能目录>/scripts/submit_feedback.py" --channel github --payload "<本地脱敏反馈.json>" --submit
```

GitHub正文公开。成功返回已核对的Issue链接；缺授权时保留草稿，不索取维护者共享密钥。`submission_unknown`表示结果未确认，只查询核对，不盲目重复创建。不能把匿名反馈擅自改投公开渠道。

## 收到之后

维护者按“待核实、需补充、已修正、不适用”跟进。核对学院、经费、日期和所引版本后，分别维护官方知识源或注明来源的学院执行口径；单次经历不会自动成为全校规则。收集反馈、核实规则、发布修正和使用者更新Skill是不同阶段。
