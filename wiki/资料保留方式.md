# 资料保留方式

按内容用途决定解析深度，不按 Word、Excel 或 PDF 的扩展名决定。学校原件、解析文字和适用性判断分别维护。

| 内容 | Wiki 与 Skill 保留方式 |
| --- | --- |
| 制度、标准、办理指南、操作步骤 | 保留完整结构化 Markdown，包含条款、正文、限制条件、表格和附注；未读内容继续标记待补。 |
| 限额表、税前税后对照、计算规则 | 保留 Markdown 表格和原表表头、人员类别、咨询方式、单位、税前税后、适用范围及脚注。公式与缓存结果分别标明，不改写成普遍适用的规则。 |
| 空白申请表、报销模板 | 提供 GitHub 原件直链与学校入口；必要的适用条件、字段说明、填表要求、承诺和注意事项仍保留为 Markdown。只有空白网格且没有说明时可只保留链接。 |
| 混合文档、填表示例 | 逐部分处理：规则和说明解析为 Markdown，空白模板提供下载；个人示例先做隐私处理，未取得或未处理的部分明确标出。 |
| 纯附件目录、重复下载入口 | 保留链接、版本及与已解析正文的关联，不把入口伪装成已读全文。 |

原件和页面预览备份在 GitHub；Skill 安装包保留文字、来源和下载链接。原件移出安装包不表示可以删除已经解析的正文。已有 Markdown 在确认内容被等价保留前，不作批量删减。

例如：[专家咨询费税前对照表](../skills/shu-baoxiao/references/sources/21fd483497f88408.md)包含标准和公式，需要保留完整可读内容；[结题确认表](../skills/shu-baoxiao/references/sources/f11d28892d5227b3.md)的承诺条件、[一次性奖励支取表](../skills/shu-baoxiao/references/sources/9ec982452a1074bd.md)的结余口径与预算调剂附注，需要和原件下载链接一起保留。

解析完整不代表规则现行有效。网页日期、文件版本年份、解析核对日期和生效日期分别记录；具体适用范围及学校后续文件仍须核对。
